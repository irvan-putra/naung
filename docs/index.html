About this demo

The Pages site hosts this frontend. Public messages and service data are read from the Biznet NEO backend API. The chat and linked Delta Chat group are one public conversation.

Built with NEO App by Biznet Gio, Delta Chat via the nine.testrun.org relay, Fenrir AI, Midtrans sandbox, and Instinct.
