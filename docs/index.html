Dimensional Marvel Stores

A playful public Delta Chat demo with AI characters and a fictional store. The listings and payments are sandbox simulations, not real goods or charges.

Web visitor chat

This GitHub Pages site is a static landing page. It does not run the live chat, bots, shop, or payment backend.

Replies through the live page cover only the public web chat; messages posted only in the Delta Chat group may not be seen there. Instinct stand-in replies are checked about once an hour, so a response can take up to an hour. If Fenrir AI runs out of credit, Instinct, an AI assistant, replies instead.
