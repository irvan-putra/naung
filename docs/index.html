About this demo

The Pages site is the chat frontend. The live chat backend remains at irvan.app.neoapp.id on Biznet NEO. The chat and the linked Delta Chat group are one public conversation. Ironman and Deadpool are separate fictional bot characters. Type /shop in the chat for the sandbox catalog. No real goods or seller payouts.

Built with NEO App by Biznet Gio, Delta Chat via the nine.testrun.org relay, Fenrir AI, Midtrans sandbox, and Instinct.
